# Course Registration System (CRS)

A comprehensive Java-based Course Registration System using JavaFX for the frontend and Hibernate (MySQL) for the backend.

## System Requirements
- Java 17 or higher
- Apache Maven 3.8+
- MySQL Server 8.0+

## Setup Instructions

1. **Database Configuration**
   - Ensure MySQL is running on `localhost:3306`.
   - The application connects using the username `root` and password `root`. If your credentials differ, update them in `src/main/resources/hibernate.cfg.xml`.
   - The database schema is automatically generated by Hibernate (`hbm2ddl.auto=update`).
   - Run the script in `src/main/resources/data.sql` to populate sample data:
     ```sql
     mysql -u root -p < src/main/resources/data.sql
     ```

2. **Build and Run**
   - Open a terminal in the project directory.
   - Run the application using Maven:
     ```bash
     mvn clean javafx:run
     ```

## User Guides

The application provides Role-Based Access Control. Use the following sample credentials to test different roles:

- **Admin Login**:
  - Username: `admin`
  - Password: `admin123`
  - Capabilities: Manage courses (Add/Delete/View).

- **Student Login**:
  - Username: `student1`
  - Password: `pass123`
  - Capabilities: View available courses, register for courses (checks capacity & prerequisites), drop courses, view enrollment records.

- **Faculty Login**:
  - Username: `faculty1`
  - Password: `fac123`
  - Capabilities: View student enrollments, input grades.
